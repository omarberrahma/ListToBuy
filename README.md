# 🛒 تطبيق قائمة مشترياتي الذكية PRO

تطبيق ويب تفاعلي موجه لمطوري الويب والمصممين في الجزائر، يتيح إدارة قائمة المشتريات مع دعم المزامنة السحابية عبر Firebase.

## 📁 هيكل المشروع

```text
.
├── css/
│   └── style.css      # ملف التنسيقات الخاص بالتطبيق
├── js/
│   └── app.js        # منطق التطبيق (Firebase، التفاعلات، AI)
├── assets/           # مجلد مخصص للملفات المساعدة (صور، أيقونات)
├── index.html        # الملف الرئيسي للتطبيق
└── README.md         # هذا الملف
```

## 🚀 المميزات

- **مزامنة سحابية:** يدعم حفظ البيانات والوصول إليها من أي جهاز عبر Firebase.
- **دعم محلي:** يعمل التطبيق بدون إنترنت (LocalStorage) في حال عدم تسجيل الدخول.
- **مقترحات AI:** استشارة الذكاء الاصطناعي للحصول على اقتراحات منتجات مفيدة للمطورين في الجزائر.
- **أرشيف يومي:** تتبع المصاريف اليومية وترتيبها حسب الوقت والتاريخ.
- **مشاركة سريعة:** نسخ ملخص المشتريات لمشاركته عبر تطبيقات التواصل الاجتماعي.
- **واجهة مستخدم ذكية:** تصميم عصري يدعم الوضع الليلي ويوفر تجربة مستخدم سلسة.

## ⚙️ إعداد Firebase

لتمويل المزامنة السحابية، يجب إعداد مشروع Firebase واتباع الخطوات التالية:

1. أنشئ مشروعاً جديداً في [Firebase Console](https://console.firebase.google.com/).
2. أضف تطبيق ويب للمشروع.
3. قم بتفعيل **Authentication** (طريقة البريد الإلكتروني وكلمة المرور).
4. قم بتفعيل **Cloud Firestore**.
5. قم بتحديث `js/app.js` بتكوين الـ Firebase الخاص بك إذا لزم الأمر، أو تأكد من تمريره عبر متغير البيئة `__firebase_config`.

## 🛠️ التقنيات المستخدمة

- **Tailwind CSS:** للتنسيق السريع والعصري.
- **Firebase v8:** لخدمات المصادقة وقاعدة البيانات.
- **Gemini AI API:** لتوليد الاقتراحات الذكية.
- **Canvas Confetti:** لإضافة لمسة جمالية عند تأكيد الشراء.

## 📝 ملاحظات

- يعتمد التطبيق على Firebase لخدمات المزامنة. إذا لم تتوفر إعدادات Firebase، سيعمل التطبيق في الوضع المحلي (LocalStorage) تلقائياً.
- تم تصميم التطبيق ليكون متوافقاً تماماً مع الهواتف الذكية (Mobile First).
